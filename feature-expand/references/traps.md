# 坑列表：写功能前扫一遍，别踩

每条都是「错的写法 → 对的写法」。写代码时对号入座，中了就改。

## 1. 只做字面功能

- 错：用户说「实现下拉框」，就渲染一个 `<select>` 完事。
- 对：识别为选择器，套 `select.md` 剧本。默认单选。选项来自 props 或接口，禁止写死业务选项。
  已确认固定 ≤20 → 不做搜索；数据来源或数量未知 → 先按会超过 20 项处理，做本地过滤；全量 ≤50 → 全量渲染；全量 51–200 → 全量渲染 + 本地过滤；全量 >200 或接口分页或会增长 → 虚拟列表或接口分页，并走服务端搜索 + 防抖 300ms + 竞态保护。
  空/加载/失败/禁用必须做；无匹配只在做了搜索时必须。
  键盘是默认路径要做的，用户要最小实现时可砍。
  用户的一句话是入口，不是全部需求。

## 2. 只做 happy path

- 错：只写「数据来了正常渲染」这一条路。空数组白屏，接口挂了白屏，加载中白屏。
- 对：每个拉数据的功能，必须同时写四条路：有数据、空数据、加载中、失败可重试。
  写完自问：这四条路我都能演示吗？

## 3. 用原生 select/table 硬撑大数据

- 错：2000 个选项塞进 `<select>`；5000 行数据直接 map 成 `<tr>`。页面卡死。
- 对：选择器 >200 项上虚拟列表或接口分页；表格走接口分页。
  原生 `<select>` 只配 ≤10 个固定选项。

## 4. 搜索不做防抖、不处理无匹配

- 错：onChange 里直接发请求，用户打 10 个字发 10 个请求，响应乱序还互相覆盖；
  搜不到时面板一片空白。
- 对：服务端搜索防抖 300ms，丢弃过期响应；无匹配显示「无匹配结果」。

## 5. 多选没有已选回显、不能清除

- 错：选了 5 项，关上面板后输入框什么都不显示；选错了没法删掉单个。
- 对：多选显示标签（超过 3 个显示「+N」），每个标签可单独删除，另有一键清空。

## 6. 表格四件套全缺

- 错：没有空数据提示（光秃表头）、数字列左对齐、加载时无骨架、
  「分页」是 `data.slice(0, 10)` 假装翻页。
- 对：空态用项目 Empty 组件；数字金额右对齐；加载骨架屏；
  做了分页时必须真翻页——第 2 页请求并显示不同数据；没做分页时禁止用 slice 假装分页。

## 7. 表单提交三连崩

- 错：提交按钮不禁用（连点发两个请求）；失败后表单被清空；错误只 toast 一句「失败」。
- 对：提交中按钮禁用 + loading；失败保留全部已填数据；
  错误写清字段和原因，如「手机号必须是 11 位数字」。

## 8. 弹层困住用户、按钮全叫「确定」

- 错：没有 Esc、点遮罩没反应、Tab 焦点跑到背景页；删除确认框按钮写「确定」。
- 对：Esc 和关闭按钮必须有；遮罩关闭默认要有，危险确认框禁止点遮罩关闭（只留按钮和 Esc）；聚焦陷阱 + 关闭归还焦点；
  危险按钮写具体动作「删除」并用危险色。

## 9. 为了「想得周到」过度设计

- 错：用户要个下拉，产出带标签管理、历史记录、收藏、导出的完整中台筛选系统。
- 对：只做剧本默认决策表里有的。表里没有、用户没提的功能，一律不做。
  「展开隐式需求」指补状态和可用性，不是加功能。

## 10. 无视项目已有组件，自己新写一套

- 错：项目里明明有 `components/Select`，还从零手写一个下拉；或者为一个弹窗新装一个 UI 库。
- 对：动手前先搜 Select / Table / Form / Modal 关键词和已装依赖。
  有现成的就复用，只补缺的行为。新写组件是最后手段，不是第一反应。

## 11. 加载中显示「暂无数据」

- 错：`data.length === 0 ? <Empty /> : <List />`，于是请求没回来时先闪一下「暂无数据」。
- 对：先判 loading，再判 error，最后才判空：loading → 骨架；error → 重试；空 → Empty。

## 12. 渲染出 undefined / null

- 错：字段缺失时单元格直接显示 `undefined`，金额显示 `NaN`。
- 对：空值统一显示「-」；数字格式化前先判空。
