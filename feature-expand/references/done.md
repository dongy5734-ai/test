# 验收清单：写完必须自检

规则：先走「通用」，再走你实现的类型那一段。
每一条都当场核对代码。缺一条就回去补，补完重新走清单。
全部通过之前，禁止声称「完成」。

## 通用（所有类型都要过）

- [ ] 空数据时，界面有可读提示，不是空白或光秃表头。
- [ ] 加载中有反馈（loading / 骨架），并且加载中不显示「暂无数据」。
- [ ] 失败时能看到原因，并且能重试。
- [ ] 禁用态存在且样式可辨认（有禁用需求的场景）。
- [ ] 没有任何地方渲染出 undefined / null / NaN。
- [ ] 复用了项目已有组件；没有另起 UI 库；没有重复造已有轮子。
- [ ] 没有做剧本决策表和用户要求之外的功能。
- [ ] 用户要最小实现时：砍的是增强项；空态、加载态、失败态、禁用态、已选回显、失败保留数据、提交中禁用按钮没被砍。

## 选择器

任何模式（包括最小实现）都不可跳过：

- [ ] 单选默认；多选是用户明确要求的。
- [ ] 选项来自 props 或接口；没有在组件里写死业务选项。
- [ ] 状态齐全：空、加载、失败可重试、禁用。
- [ ] 关面板后能看到当前值（已选回显）；多选有标签且可单独删除、可清空。
- [ ] 没有用原生 `<select>` 撑大数据或搜索场景。

增强项——用户明确说「只要最小实现 / 先出个 demo / 不要多余功能」时可跳过，否则必须做：

- [ ] 搜索口径与 select.md 一致：已确认固定 ≤20 → 不做搜索；数据来源或数量未知 → 先按会超过 20 项处理，做本地过滤；全量 51–200 → 全量渲染 + 本地过滤；只有接口分页或数据会随业务增长才服务端搜索 + 防抖 300ms + 竞态保护。
- [ ] 做了搜索时有无匹配态：搜不到显示「无匹配结果」。
- [ ] >200 项没有全塞进 DOM（虚拟列表或接口分页）。
- [ ] 键盘：默认路径必须做（打开、上下、回车选中、Esc 关闭、输入即过滤）；用户明确说「只要最小实现 / 先出个 demo / 不要多余功能」时可砍。

## 表格列表

任何模式（包括最小实现）都不可跳过：

- [ ] 空数据、加载（骨架或 loading 行）、失败重试三态齐全。
- [ ] 文本左对齐、数字金额右对齐、操作列在最右。
- [ ] 空值单元格显示「-」，没有渲染出 undefined / null / NaN。
- [ ] 增删改成功后刷新了当前页数据（有增删改时）。
- [ ] 没有做用户没要的排序、筛选、导出。
- [ ] 没有用 slice 假装分页：要么不做分页，要么第 2 页真的请求并显示不同数据。

增强项——用户明确说「只要最小实现 / 先出个 demo / 不要多余功能」时可跳过，否则必须做：

- [ ] 分页（仅一次全返且 ≤100 条时可跳过）：接口分页传 page/pageSize，翻页重新请求且有加载反馈。
- [ ] 时间列格式化成项目惯用格式。
- [ ] 长文本超宽省略号 + hover 提示。

## 表单

任何模式（包括最小实现）都不可跳过：

- [ ] 提交时校验全部并聚焦第一个错误。
- [ ] 错误显示在字段旁，文案写清哪里错、怎么改；不是只 toast「失败」。
- [ ] 提交中按钮禁用 + loading，连点不会发两个请求。
- [ ] 失败后已填数据全部还在，可直接重试。
- [ ] 成功后有明确反馈；新增重置、编辑保留。
- [ ] 仅编辑场景做回填和回填加载态；新增/纯提交场景没有做回填，没有凭空做一套编辑流程。
- [ ] 有上传字段时：选文件时就校验类型和大小，失败可重传。

增强项——用户明确说「只要最小实现 / 先出个 demo / 不要多余功能」时可跳过，否则必须做：

- [ ] 失焦时校验单字段（砍了失焦时，提交时全量校验、字段旁错误、聚焦第一个错误仍必须）。
- [ ] 编辑回填期间用骨架屏（砍掉骨架屏也必须留简单加载态）。
- [ ] 上传进度展示。

## 弹层

最小实现只可跳过：输入名称二次确认、抽屉化。下面各条任何模式都不可跳过。

- [ ] Esc 可关；遮罩可关（危险确认除外）；有关闭按钮。
- [ ] 焦点进入弹层且 Tab 不逃逸；关闭后焦点回到触发元素。
- [ ] 危险按钮写具体动作（「删除」），危险色；没有一个按钮叫「确定」。
- [ ] 确认文案写清对象和后果。
- [ ] 提交中按钮禁用且弹层不可关闭；失败保留弹层并显示原因。
- [ ] 打开时背景锁滚动；内容超高时弹层内部滚动。
- [ ] 关闭后内部状态已重置，重新打开无残留。
