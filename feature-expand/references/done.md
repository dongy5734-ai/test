# 验收清单：写完必须自检

规则：先走「通用」，再走你实现的类型那一段。
每一条都当场核对代码。缺一条就回去补，补完重新走清单。
全部通过之前，禁止声称「完成」。

## 通用（所有类型都要过）

- [ ] 空数据时，界面有可读提示，不是空白或光秃表头。
- [ ] 加载中有反馈（loading / 骨架），并且加载中不显示「暂无数据」。
- [ ] 失败时能看到原因，并且能重试。
- [ ] 禁用态存在且样式可辨认（有禁用需求的场景）。
- [ ] 没有任何地方渲染出 undefined / null / NaN。
- [ ] 复用了项目已有组件；没有另起 UI 库；没有重复造已有轮子。
- [ ] 没有做剧本决策表和用户要求之外的功能。
- [ ] 用户要最小实现时：砍的是增强项，空/错/禁用没被砍。

## 选择器

- [ ] 单选默认；多选是用户明确要求的。
- [ ] 选项 >20 有过滤；接口数据用服务端搜索且防抖 300ms。
- [ ] >200 项没有全塞进 DOM（虚拟列表或接口分页）。
- [ ] 五态齐全：空、加载、无匹配、失败可重试、禁用。
- [ ] 关面板后能看到当前值；多选有标签且可单独删除、可清空。
- [ ] 键盘：打开、上下、回车选中、Esc 关闭、输入即过滤。
- [ ] 没有用原生 `<select>` 撑大数据或搜索场景。

## 表格列表

- [ ] 分页是真的：第 2 页请求并显示不同数据，不是 slice。
- [ ] 空数据、加载骨架、失败重试三态齐全，翻页时也有加载反馈。
- [ ] 文本左对齐、数字金额右对齐、操作列在最右。
- [ ] 空值单元格显示「-」；时间列已格式化。
- [ ] 增删改成功后刷新了当前页数据。
- [ ] 没有做用户没要的排序、筛选、导出。

## 表单

- [ ] 失焦校验单字段；提交校验全部并聚焦第一个错误。
- [ ] 错误显示在字段旁，文案写清哪里错、怎么改；不是只 toast「失败」。
- [ ] 提交中按钮禁用 + loading，连点不会发两个请求。
- [ ] 失败后已填数据全部还在，可直接重试。
- [ ] 成功后有明确反馈；新增重置、编辑保留。
- [ ] 编辑场景回填前有加载态。
- [ ] 有上传字段时：有进度、失败可重传、选文件时就校验类型和大小。

## 弹层

- [ ] Esc 可关；遮罩可关（危险确认除外）；有关闭按钮。
- [ ] 焦点进入弹层且 Tab 不逃逸；关闭后焦点回到触发元素。
- [ ] 危险按钮写具体动作（「删除」），危险色；没有一个按钮叫「确定」。
- [ ] 确认文案写清对象和后果。
- [ ] 提交中按钮禁用且弹层不可关闭；失败保留弹层并显示原因。
- [ ] 打开时背景锁滚动；内容超高时弹层内部滚动。
- [ ] 关闭后内部状态已重置，重新打开无残留。

## 最后一问

把用户的原话再读一遍。他真正要用这个功能干什么？
拿上面对应的清单核对完之后，自己以用户身份把主流程点一遍（或跑一遍测试）。
点得下去、看得明白、错了能重来，才算完成。
